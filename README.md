# Dig Through Time

Пиксельный шахтёр: копаешь вниз сквозь эпохи и отстраиваешь деревню наверху. Диздок — в [docs/GDD.md](docs/GDD.md).

## Запуск

Из папки `CLAUDE CODING`:

```bash
python3 dig-through-time/tools/devserver.py 8770
```

Открыть http://localhost:8770. Этот сервер отключает кэш, поэтому правки видны сразу после перезагрузки.

## Управление — только стрелки

| Клавиша | Где | Действие |
|---|---|---|
| ← → | везде | ходить; упёрся в блок — копаешь, рядом враг — бьёшь киркой |
| ↑ | под землёй | прыжок |
| ↑ | у двери | войти в здание |
| ↓ | на люке шахты | спуститься в шахту |
| ↓ | под землёй | копать вниз |

Факел, подъём наверх, карта и меню — кнопками на экране. Мышью и пальцем можно копать соседний блок или идти к точке.

## Что есть

- **Шахта.** Вход один — люк в центре деревни, под деревней копать нельзя. Слои идут волнами, между эпохами есть переходные зоны.
- **Свет.** Фонарь тускнеет ниже своей «рабочей» глубины, поэтому его нужно улучшать. Факелы горят всегда.
- **Жизни.** Урон наносят лава, крысы и босс. Здоровье восстанавливается на поверхности или после отдыха дома. При обмороке теряешь рюкзак.
- **Обвалы.** Иногда случаются после подъёма наверх: засыпает часть выкопанных тоннелей, место не сообщается.
- **Карта** показывает только то, что ты видел. Обвал на ней появится, когда ты его увидишь.
- **Апгрейды.** Кирка — 10 уровней, у каждого свой цвет: дерево → камень → медь → железо → золото → алмаз → изумруд → рубин → обсидиан → хроно. Чем лучше кирка, тем больше урон. Рюкзак — 10 уровней, фонарь — 8.
- **Деревня:**
  - ферма (грядки, курицы, овцы, коровы);
  - дом (3 уровня, 11 предметов мебели, отдых);
  - ратуша (7 построек дают бонус к цене руды, мельница ускоряет рост урожая);
  - дом гномов (копают, даже когда игра закрыта, до 8 часов);
  - портной (8 скинов).
- **Эпоха II целиком.** Глина, руины с факелами, серебро, золото, рубины, лава, крысы, Крысиный король. За ним печать и конец текущего контента.
- **Сохранения.** Игра сразу продолжается с автосохранения, в меню есть 3 слота и новая игра, после перерыва показывается окно «пока тебя не было». Тексты на EN / RU / ES.

## Структура

```
index.html        HUD, окна, стили
src/i18n.js       тексты EN / RU / ES и истории артефактов
src/data.js       баланс: блоки, цены, апгрейды, ферма, гномы, мебель, скины
src/art.js        весь пиксель-арт, рисуется кодом
src/world.js      генерация мира по seed: слои, руины, лава, зал босса
src/sim.js        логика фермы, гномов, бонусов (по реальному времени)
src/save.js       автосохранение + 3 слота
src/ui.js         окна зданий, меню и сохранения, мини-карта
src/enemies.js    крысы и Крысиный король
src/village.js    деревня на поверхности
src/game.js       сцена Phaser: копание, свет, жизни, обвалы
src/sfx.js        звуки (синтез Web Audio)
tools/devserver.py  локальный сервер без кэша, сохраняет файлы в release/
tools/build.sh    сборка игры в release/build
tools/covers.html обложки 1920×1080, 800×1200, 800×800
tools/record.js   запись превью-видео из игры
tools/make-videos.sh  склейка видео через ffmpeg
```
